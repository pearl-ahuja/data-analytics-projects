# Classic Models Sales Dashboard

## Tools Used
- SQL
- Power BI

## Project Overview
This project analyzes sales data from the Classic Models database to track revenue, product performance, and customer trends.

## Key Insights
- Net Profit analysis by product line, countries, and cost of sales
- Customer purchasing behavior
- Performance of top-selling products
