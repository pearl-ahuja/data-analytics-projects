# Netflix Data Analysis Dashboard

## Tools Used
- Excel
- SQL
- Power BI

## Project Overview
This project analyzes Netflix content data to identify trends across genres, countries, and release years.

## Key Insights
- Distribution of movies vs TV shows over the years
- Popular genres and content trends
- Rating of movies and TV shows
- Variation among different countries
- All the details of selected show
